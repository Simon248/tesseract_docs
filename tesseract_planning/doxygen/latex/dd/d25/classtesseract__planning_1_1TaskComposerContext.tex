\doxysubsection{Detailed Description}
This class is passed as an input to each process in the decision tree. 

Container for use internally by tasks and task executors to facilitate the execution of tasks

This object contains\+:
\begin{DoxyItemize}
\item {\ttfamily Task\+Composer\+Problem}\+: represents the mutable input data needed to initiate the task and additional meta-\/data.
\item {\ttfamily \doxylink{classtesseract__planning_1_1TaskComposerDataStorage}{Task\+Composer\+Data\+Storage}}\+: container in which tasks are expected to find their required input data and where tasks should save their results at run-\/time. This class member is originally set equal to the {\ttfamily \doxylink{classtesseract__planning_1_1TaskComposerDataStorage}{Task\+Composer\+Data\+Storage}} member of the {\ttfamily Task\+Composer\+Problem}, which represents the immutable input data for the task
\item {\ttfamily \doxylink{classtesseract__planning_1_1TaskComposerNodeInfoContainer}{Task\+Composer\+Node\+Info\+Container}}\+: container for meta-\/data generated by \doxylink{tesseract__task__composer__core__unit_8cpp_aff72eefedb05c0f13d6346b099a22a7f}{task(s)} during execution. 
\end{DoxyItemize}
